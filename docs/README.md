# Foreman Documentation

The approved product contract and current implementation plan live in [`brain/`](../brain/README.md).

This directory is reserved for user and contributor documentation that describes implemented Foreman behavior. Documentation must not claim a capability before its implementation and verification evidence exist.

Current command help is available through:

```sh
./bin/foreman --help
```

The current initialization and plan-review workflow is documented in [Getting started](getting-started.md). The recommended plan shape is available in the [plan template](plan-template.md).
